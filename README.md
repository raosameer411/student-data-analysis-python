# Student Data Analysis Using Python

## Overview

This project is a simple Student Data Analysis System built using Python, NumPy, and Pandas. It stores student information and performs various analyses such as marks evaluation, attendance tracking, and performance reporting.

## Features

* Store student data
* Calculate average marks
* Find highest and lowest marks
* Filter students based on marks
* Analyze attendance records
* Generate student performance reports
* Display data in tabular format using Pandas

## Technologies Used

* Python
* NumPy
* Pandas

## Dataset

The dataset contains information for 20 students:

* Name
* Age
* Marks
* Attendance

## Analysis Performed

* Average Marks Calculation
* Highest Marks Identification
* Lowest Marks Identification
* Student Filtering
* Attendance Analysis
* Grade Assignment
